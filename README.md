# MyResume

Static CV hosted on GitHub Pages at https://nlevinh.github.io/MyResume/.

## Download PDF

Click **Download PDF** on the website. [pdf-export.js](./pdf-export.js) preserves the HTML colors, gradients, logos and shadows in an A4 PDF, with page breaks that avoid cutting text lines. The PDF contains high-resolution images; its text is not selectable.

No backend, build step or offline bundle is needed. Images and PDF libraries are served from the repository using relative paths. Publish the updated files through the existing GitHub Pages workflow.
